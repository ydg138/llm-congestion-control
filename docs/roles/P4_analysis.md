## 발표 때 설명할 수 있어야 하는 것

- **Jain 공정성 지수**: (Σx)² ÷ (n × Σx²). 모두 같으면 1, 한 명이 다 가져가면 1/n
- **왜 평균이 아니라 p95를 보나**: 대부분은 빨라도 일부가 아주 늦으면 사용자는 그 늦은 쪽을 느낀다. 꼬리 지연이 중요하다
- **AIMD 그래프가 왜 톱니 모양인가**: 덧셈으로 천천히 늘다가 429에서 곱셈으로 뚝 떨어지기를 반복하기 때문 (4주차)
- **한도 활용률이 100%가 아닌 이유**: 톱니의 아래쪽 구간에서는 한도를 다 쓰지 못한다. 이것이 AIMD가 "잃는 것"
- **E1~E6 결과 요약**: 각 실험이 무엇을 보여 줬는지 한 문장씩
